# 第一部分　基础概念篇

v2 第 2 节已讲清的概念，这里只给一句定义加出处。网络（第 4 组）和电力（第 5 组）是 v2 的空白，在本篇新写。

## 1. 算力怎么计量

| 概念 | 一句话 | 出处 |
|---|---|---|
| FLOPS 与数值精度 | 每秒浮点运算次数。同一颗芯片在 FP4、FP8、BF16 下的峰值不同，比较时必须同精度、同稀疏口径 | 见 v2 §2「算力是什么」「训练与推理对芯片的要求」 |
| MFU | 有效模型计算占理论峰值的比例。Epoch AI 在预训练测算中假设 15%–35% | 见 v2 §2 运行指标表 |
| token | 模型处理或生成的文本单位，是 API 计费单位 | 见 v2 §2 计量单位表 |
| GPU 小时 / 卡时 | 一块 GPU 用一小时，是租赁和价格指数的计价单位；国内常用“卡时” | 见 v2 §2；H200 调研 |
| GW / MW：IT 负载 vs 园区总供电 | GW IT（Critical IT）只算 IT 设备负载；园区总供电 = IT 功率 × PUE。两种口径不能混用 | 见 v2 §2、核2 |
| GW ↔ 机柜 ↔ GPU | 示意换算：GB200 NVL72、140 kW/柜、PUE 1.25 时，1 GW IT ≈ 7100 柜 ≈ 51 万 GPU | 见 v2 §2（示意假设，非行业标准） |
| P（PFLOPS）计价 | 国内智算中心常按“P”报规模和租价。要注意精度口径，FP16 和 FP8 的 P 不可比 | 回本周期文章（赓哥聊创投）；口径**待核** |

## 2. 芯片与系统

| 概念 | 一句话 | 出处 |
|---|---|---|
| GPU / 定制 ASIC / AI 原生芯片 | 通用 GPU 谁都能买；ASIC 由大厂和设计服务商（Broadcom、Marvell）定制、主要自用；AI 原生芯片多用片上 SRAM 或存内计算专攻解码 | 见 v2 §3 三条路线 |
| 芯片代际 | Hopper（H100/H200）→ Blackwell（B200/GB200）→ Blackwell Ultra → Rubin；每代的 HBM 容量和带宽提升大于单卡算力提升 | 见 v2 §2 产品表、代际表 |
| 超级芯片与整机柜 | GB200 = Grace CPU + 2 颗 GPU；NVL72 = 72 颗 GPU 用 NVLink 连成一个液冷机柜，按整柜交付 | 见 v2 §2 |
| HBM | 堆叠在 GPU 旁的高带宽内存，决定能放多大模型、解码多快；推理时常比算力更早成为瓶颈 | 见 v2 §2、§3 |
| CoWoS（先进封装） | 台积电把 GPU 裸片和 HBM 封在同一中介层上的工艺，是 AI 芯片产能的关键卡点 | 见 v2 §2「五个层级」 |
| CUDA 与软件生态 | 英伟达的护城河之一；ASIC 需自建软件栈，迁移有成本 | 见 v2 §3 对比表（◐ 尚无专门展开） |
| 制程与光刻 | 先进制程（3nm、2nm）依赖 EUV 光刻，EUV 由 ASML 独家供应；中国大陆受限于此，主要用 DUV 多重曝光 | 新写，见 A2 层 ASML、中芯卡片 |

## 3. 训练与推理

| 概念 | 一句话 | 出处 |
|---|---|---|
| 训练 vs 推理 | 训练是集中投入的研发支出，前沿集群上万到十万卡；推理随用户请求持续发生，计入收入成本 | 见 v2 §2 对比表 |
| 预填充 / 解码 / PD 分离 | 预填充处理输入，偏计算密集；解码逐个生成 token，受内存带宽限制。两阶段可以分池部署 | 见 v2 §2 及图 2 |
| KV cache | 缓存已处理内容的注意力中间结果，长上下文和高并发会增加显存占用 | 见 v2 §2 |
| 批处理与吞吐-时延权衡 | 合批提高吞吐、摊薄权重读取，但受用户可接受的延迟约束 | 见 v2 §2 |
| MoE、稀疏/线性注意力、扩散 LM | 降低每 token 计算量或 KV 占用的架构路线，对互连和内存提出新要求 | 见 v2 §2 新技术路线表 |
| 算力乘数 | 推理模型、强化学习、agent 长任务让完成一个任务的算力成倍增加 | 见 v2 §1、`算力.pdf`（◐） |
| 每百万 token 成本 | 硬件、利用率、软件共同决定的推理单位成本 | 见 v2 §2 代际段（InferenceX 数据） |

## 4. 互连与网络（新写）

**为什么重要**：大模型要上万颗芯片像一台机器那样协同。芯片之间的数据交换速度决定了集群实际用上多少理论算力，网络因此是除芯片、HBM 之外的第三个硬件瓶颈。

| 概念 | 讲清楚什么 |
|---|---|
| **Scale-up vs Scale-out** | **Scale-up（纵向）**：一个“超节点”内部的芯片互连，带宽最高、延迟最低，GPU 之间可以直接读写彼此的显存。英伟达用 NVLink + NVSwitch，NVL72 即 72 卡一个 scale-up 域；华为用灵衢（UB）总线做超节点（见 A1 华为卡片）。**Scale-out（横向）**：超节点之间、机柜之间组网，用 InfiniBand 或以太网，规模可达十万卡以上，带宽和延迟都比 scale-up 差一个量级。训练中的张量并行和 MoE 专家并行流量主要走 scale-up，数据并行和流水线并行可以走 scale-out |
| **NVLink / NVSwitch** | 英伟达私有的芯片间互连协议和交换芯片。2025 年起英伟达推出 NVLink Fusion，允许第三方 CPU 或 ASIC 接入 NVLink 生态（具体授权范围**待核**） |
| **InfiniBand vs 以太网** | **InfiniBand**：为高性能计算设计的无损、低延迟网络，英伟达收购 Mellanox 后基本独家供应，早期 AI 训练集群主要用它。**以太网**：开放标准、供应商多（Broadcom、Arista、Cisco、英伟达 Spectrum-X），通过 RoCE（以太网上的 RDMA）实现低延迟；超以太网联盟（UEC）在推动面向 AI 的规范。大厂出于成本和避免单一供应商的考虑，越来越多转向以太网。具体份额变化放到 A4 层写 |
| **交换机 / 交换芯片** | 交换芯片（Broadcom Tomahawk/Jericho、英伟达 Spectrum/Quantum）决定单台交换机的端口带宽；交换机厂商（Arista、Cisco、白盒 ODM）做整机和软件。集群越大，网络层级越多，交换机用量和光模块用量越高 |
| **网卡 / DPU / SuperNIC** | 每台服务器出口的网卡（如英伟达 ConnectX、BlueField），负责 RDMA 和网络卸载 |
| **光模块（800G/1.6T）** | 把电信号转成光信号，在机柜间和长距离上传输。速率按代翻倍（400G → 800G → 1.6T），主要供应商包括中际旭创、新易盛、Coherent 等。光模块数量随集群规模和网络层数增加 |
| **CPO（共封装光学）** | 把光引擎和交换芯片封在一起，省去可插拔光模块，降低功耗。英伟达在 Rubin 平台的 Spectrum-6 交换系统中同时支持可插拔光学和 CPO（见 A1 英伟达卡片来源 S1）。CPO 对可插拔光模块厂商的替代节奏**待核** |
| **铜缆与 retimer（AEC/DAC）** | 柜内和短距离用铜缆，比光模块便宜、省电；NVL72 柜内 NVLink 走铜缆背板。有源铜缆（AEC）和 retimer 芯片用来延长铜缆距离（Credo、Astera Labs） |
| **集合通信** | All-Reduce 等集合通信操作在训练每一步同步梯度。网络拥塞或单点故障会拖慢整个集群，这是大集群 MFU 偏低的主要原因之一 |

## 5. 数据中心与电力（新写为主）

**为什么重要**：芯片到货后，要有通了电、装好液冷的机房才能变成可用算力。v2 §6 的结论是：美国扩产的约束从 2024 年起已从芯片转向电力，再转向资金和地方审批。

| 概念 | 讲清楚什么 |
|---|---|
| **IT 负载、园区总供电与 PUE** | 见第 1 组。注意：电网接入容量、园区总供电、IT 负载、实际运行功率是四个不同的数 |
| **机柜功率密度** | 传统机柜约十几 kW；NVL72 级 AI 机柜在 100 kW 以上（v2 用 140 kW 作示意），必须改用液冷和更高电压的配电 |
| **液冷** | 冷板式：冷却液经过芯片上的冷板，是 NVL72 的主流方案。浸没式：整机泡在绝缘液中。CDU（冷却液分配单元）是液冷系统的核心设备，详见 B7 层 |
| **并网与排队** | 新的大负荷要向电力公司或电网运营商申请接入，经过研究、审批、建设输变电设施。美国主要市场等待时间数年（JLL 称平均超过四年，见 v2 §2「建设开发与投产周期」） |
| **表后发电（behind-the-meter）** | 发电设施建在用户“电表之后”，直接给园区供电，不经过（或不完全依赖）公共电网。常见形式：燃气轮机、往复式燃气发动机、燃料电池，加电池储能平滑负荷。**好处**：不用排并网队，通电快。**代价**：要自己承担燃料（多为天然气管道）、排放许可、冗余备份和运维，单位电价通常高于电网（具体成本差**待核**，B6 层补）。案例：xAI Colossus 接入电网时只有 8 MW，靠移动式燃气轮机补电（见 v2 §2）。SemiAnalysis《Datacenters 2027》说“发电问题已基本解决”，指的就是这类方案让大园区能按时通电；它**没有**判断 2027 年整体电力供需平衡，作者模型反而显示美国电网富余容量到 2027 年底转负（见研报笔记与 11/16 讨论） |
| **桥接电源与长期电源** | 很多园区先用表后发电“桥接”，等并网完成后转为电网供电，表后机组改作备用。长期电源可以是电网购电、PPA（长期购电协议），或与核电站共址 |
| **PPA（长期购电协议）** | 用电方与发电方签 10–20 年的固定或指数化电价合同，锁定电量和电价。大厂与核电运营商（如 Constellation）的 PPA 属于此类，详见 B6 层 |
| **发电设备** | 大型燃机（GE Vernova、西门子能源、三菱重工），交期长，是 2024–25 年的瓶颈之一；往复式发动机（Caterpillar、瓦锡兰等），单机小、上量快；燃料电池（Bloom Energy）；SMR 小型核反应堆，多为 2030 年前后的远期规划 |
| **变压器与开关柜** | 从高压电网降压到机房用电需要变压器和开关柜。v2 §2 指出“变压器、燃气轮机等设备的交期已排到数年以后” |
| **备用电源与冗余（Tier）** | UPS（不间断电源）加柴油或燃气发电机，保证断电时不中断。Uptime Institute 的 Tier I–IV 分级：Tier III 要求可在线维护，Tier IV 要求容错。AI 训练园区有时降低冗余要求以节省成本（具体做法**待核**） |
| **数据中心的交付形态** | **Powered shell**：只交付通了电的空壳厂房。**Build-to-suit**：按租户规格定制建设。**批发租赁**：按 MW 整租给大客户，期限常在十年以上。**零售托管（colocation）**：按机柜出租。不同形态对应不同的资本投入和风险分配（见 v2 §4「算力云的资产持有方式」） |
| **开发周期** | 选址 → 拿电 → 地方审批 → 建设 → 上架调试，部分环节并行，不能简单相加（见 v2 §2） |
| **电价与地方政治** | 2026 年起电价上涨让数据中心审批变成地方政治议题，中期选举 41 项地方投票中有 40 项否决了开发计划（见 v2 研究问题、JPM 11/4 研报笔记） |

## 6. 算力经济学

| 概念 | 一句话 | 出处 |
|---|---|---|
| GPU 小时定价：按需 vs 长约 vs 现货 | 按需价随时可停、风险在卖方；长约照付不议、风险在买方；现货指数反映边际供需 | 见 v2 §4 交易表；Ornn、Silicon Data 研报笔记 |

# 第二部分　分层图谱

## A1　加速芯片设计与 IP

**这一层做什么**：设计 GPU 和 AI 加速器及其软件栈。通用 GPU 卖给所有买家；定制 ASIC 由大厂和模型厂商主导设计，Broadcom、Marvell 提供设计服务和量产交付。EDA（Synopsys、Cadence）和 IP（Arm）是设计工具和积木。

**怎么赚钱**：按件卖芯片或整机柜，ASIC 收设计费再按量供货。这是产业链利润最厚的环节之一：英伟达 Q2 FY27 GAAP 毛利率 75.0%、营业利润率约 66.2%（见 S1、v2 §3）。

**本层要点**
- 英伟达的规模仍远大于其他厂商：数据中心季度收入 890 亿美元（Q2 FY27）。对比 AMD 数据中心分部 85 亿美元（Q3 2026，含 CPU）、Broadcom AI 半导体 167 亿美元（Q3 FY26，含 ASIC 和 AI 网络）。三家口径不同，不能直接算份额。
- 定制 ASIC 的增速最快：Broadcom AI 半导体收入同比 +221%，公司称已为 FY27 约 1150 亿美元 AI 收入锁定供应。英伟达的供应与产能承诺一个季度内从 1190 亿增至 2790 亿美元，“主要是内存采购”。上游的锁量竞争集中在 HBM 和 CoWoS 上。

## A2　晶圆制造、先进封装与半导体设备

**这一层做什么**：
- 代工厂用先进制程制造 GPU 和 ASIC 裸片。
- 先进封装（台积电 CoWoS 及其他厂商的 2.5D/3D 方案）把裸片和 HBM 封在一起。
- 封测厂承接外溢的封装和测试订单。
- 设备商（光刻、刻蚀、沉积、量测）决定产能能扩多快。

**怎么赚钱**：代工按晶圆计价；封装按颗或按晶圆计价；设备按台销售，再加长期的装机服务收入。

**本层要点**
- 台积电是 AI 芯片的单点依赖：HPC 平台占 Q3 2026 收入的 68%，7nm 及以下先进制程占晶圆收入的 79%，营业利润率 58.7%。2026 年 capex 指引维持 600 亿–640 亿美元（CFO 表述，经 Focus Taiwan 转述），其中 10%–20% 用于先进封装、光罩等（比例来自电话会摘要，**待核**原文）。
- 设备端的信号最长：ASML 称部分客户已有意向下 2029、甚至 2030 年的订单，按当前规划，2027–28 年的产能满足不了客户需求。这是 ASML 管理层对订单兴趣的表述，不是已签订单。
- 中国栏：中芯国际产能利用率 97.3%，但中国区收入占 90.8%，说明它主要服务本土需求。长电科技把 2026 年投资计划上调到 182 亿元，主要投向先进封装。北方华创 Q3 收入同比只增 1.3%，国产设备的增速没有跟上国内晶圆厂的 AI 叙事，原因**待核**。

**其他参与者**：三星代工、英特尔代工（先进封装 EMIB/Foveros）、Amkor、Lam Research、东京电子、KLA；华虹、中微公司、通富微电。

## A3　存储（HBM / DRAM / NAND）

**这一层做什么**：
- HBM 和 GPU 封在一起，决定单卡能放下多大的模型、解码多快。
- 服务器 DRAM（DDR5、SOCAMM）服务 CPU 和推理侧内存。
- NAND/企业级 SSD 存放训练数据、checkpoint 和 KV cache 外溢。
- 同样容量的 HBM 比普通 DRAM 占用更多晶圆，所以扩 HBM 会挤掉通用 DRAM 的供给（见 v2 §3）。

**怎么赚钱**：按颗或按 GB 卖芯片。HBM 一向以长约为主；2026 年起 DRAM 和 NAND 也转向多年期合同（见 v2 §3）。

**本层要点**
- 2026 年存储超级周期把利润推到了产业链最高：SK 海力士 Q3 营业利润率 80%，美光 FQ4-26 GAAP 营业利润率 80.7%，三星 DS 部门营业利润 106.5 万亿韩元。对比英伟达营业利润率约 66%，v2 说的“利润正在向存储转移”已经出现在财报里。
- 长约正在改变周期属性：SK 海力士与 14 家大客户签了长期协议（LTA），覆盖 2027–28 年一半以上的产能，价格在约定区间内随市场浮动；美光有“战略客户协议”。需求放缓时，风险转到买方（英伟达、云厂商）身上（与 A1 英伟达 2790 亿美元承诺对照着看）。
- 中国栏：长鑫、长江存储利润暴增，主要来自通用 DRAM/NAND 涨价，**不是 HBM**。长鑫招股书没有披露任何 HBM 收入或量产，国产 HBM 仍是昇腾等国产芯片的短板（华为称 950 系列开始用自研 HBM，见 A1）。

**其他参与者**：铠侠、闪迪（NAND）、希捷、西部数据（HDD）。

- **客户**：前十几家大客户包括全球主要云厂商（S43 称 14 家 LTA 客户）；英伟达是主要 HBM 客户（v2 §3）。

  - 公司预计 2027 年随着龙仁一期全面投产，投资将“大幅增加”（S43）。
  - 2026 年计划股东回报约 100 万亿韩元（S43）。
- **近期动作**：

  - 三星 HBM4 追赶。
- **中国关联**：无锡、大连有 DRAM/NAND 产线，受设备出口管制影响，具体**待核**。
- **在现有材料中的位置**：v2 核心判断、§3 利润率表与芯片长约段；H200 调研。
