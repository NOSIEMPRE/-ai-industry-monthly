# 算力产业图谱维护方案 v1

更新日期：2026-11-25

## 目标

图谱用于回答三个问题：算力产业链每一层卖什么、谁向谁付费、最近两三个月发生了什么变化。底图负责稳定的产业结构，玩家台账负责公司层面的可比字段，动态台账负责新事件和变化判断。三者分开维护，避免每次更新都重写整篇正文。

当前底图为四段十三层：

```text
A 硬件供给：芯片设计与 IP → 制造/封装/设备 → 存储 → 网络与互连 → 服务器/整机柜
B 物理基础设施：电力与能源 → 机电与冷却 → 数据中心开发与运营
C 算力供给：超大云厂商 → Neocloud / GPU 云与推理平台
D 资金、定价与需求：算力交易与定价 → 融资与信用 → 模型厂商需求 → 中国算力生态
```

底图文件为 `算力行业全图谱.md`，公司层字段在 `玩家台账.csv`，事件层字段在 `动态跟踪台账.csv`。

## 每次更新的最小单元

一条更新必须同时写清：

1. **事件**：发生了什么，日期和原始来源是什么。
2. **所在层**：影响哪一层、哪家公司或哪条上下游关系。
3. **机制**：事件改变了供给、需求、价格、融资、交付或利润中的哪一项。
4. **两三个月比较**：相对窗口起点是上升、下降、迁移还是暂未改变。
5. **判断边界**：公司披露、机构预测、平台样本和本文推论分开标记。

事件没有同时满足“日期、来源、影响层、变化方向”四项时，放入待核项，不进入趋势结论。

## 动态窗口和输出

- **滚动窗口**：默认观察最近 90 天；重大合同、产能、融资和政策事件可追溯至 180 天。
- **周度**：只更新 `动态跟踪台账.csv`，标记新增事件和待核来源。
- **月度**：更新玩家卡片中的“近期动作”和“主要风险”，形成一页“本月图谱变化”。
- **季度**：以公司财报、监管文件、官方定价和容量披露为主，重算规模、利润率、债务和利用率字段。

月度变化页按以下顺序写：

1. 产业链结构是否改变；
2. 哪些环节的供给或需求约束变强或变弱；
3. 头部公司的定位、客户或合同是否改变；
4. 上下游关系和资金风险如何重新分配；
5. 哪些变化仍只有单家公司或样本平台证据。

## 数据优先级和口径

一手来源优先级为监管文件和财报、公司公告与官方业绩会、政府和电网资料、机构原始报告、平台原始数据。媒体和研报转述只作为线索，不能单独支撑关键数字。

固定检查项：

- 收入、利润率、capex 和债务保留报告期及发布日期；公司整体指标与算力分部指标分开。
- GW 区分 IT 负载、园区总供电和获批电力容量；“承诺、签约、在建、通电、可用”不混为一项。
- 芯片、GPU 小时、卡时、token、MW/GW 不互相换算，除非写明假设、功率边界和设备代际。
- 长约、take-or-pay、预付款、租赁、债务和股权投资分别记录；不能把合同总额当作已到账收入或债务余额。
- 利润率比较只在报告期、分母和会计口径可比时进行；平台价格只代表平台样本。

## 当前基线（核查至 2026-11-17）

- A1 至 A3 已完成一轮公司卡片和来源表，覆盖英伟达、AMD、Broadcom、Google TPU、华为昇腾、寒武纪、海光、摩尔线程，台积电、ASML、应用材料、日月光、中芯国际、北方华创、长电科技，以及 SK 海力士、三星、美光、长鑫、长江存储等。
- 现有图谱已把芯片、HBM、CoWoS、网络、服务器、电力、液冷、数据中心、云厂商、Neocloud、算力交易、融资和中国生态放入同一张图，但 A4 至 D13 的公司卡片和来源仍需按同一字段补齐。
- 最近一轮变化的主要观察点是：先进封装和 HBM 仍是上游锁量重点；供应约束逐渐向电力、液冷、并网和交付迁移；Neocloud 的客户合同、债务和 GPU 经济寿命继续决定中游风险；中国厂商的收入增长已进入台账，但出货、客户、毛利率和国产替代比例仍有待逐项核实。

上述三条是基于现有材料的阶段性判断，不外推为全行业统计结论。
