# AI 产业月度研讨（商业与投资）

面向院领导与研究员的月度 AI 产业研讨材料项目。项目采用**数据与视图分离**的轻量静态架构，无需构建工具即可在本地双击打开（支持 PC 端与移动端自适应），同时可直接托管至 GitHub Pages，确保每期滚动更新以**精准修改单模块数据**为核心，而非整篇重写网页。

> **核心原则**：网页展示层只呈现干净的事实、判断、图表与产业趋势；一切过程说明、入选标准、日报抓取需求、待办与待核查事项全部沉淀在本 `README.md` 与 [`更新日志.md`](./更新日志.md) 中，绝不留在展示网页内。

## 二、月度滚动更新 SOP（精准修改指南）

1. **新建月份数据目录**：复制 `data/2026-11/` 为 `data/2026-12/`。
2. **按模块精准更新数据**（无需改动 CSS/HTML 布局）：
   - 改封面与章节导语 → 编辑 `meta.js`
   - 增删单条重点新闻 → 编辑 `news.js`（编号、封面页数、侧边目录会自动同步，不会出现断链）
   - 更新机构趋势与图表 → 编辑 `trends.js`（如需新增图表类型，在 `assets/charts.js` 中注册一个 SVG 渲染函数）
   - 更新投融资趋势与明细 → 编辑 `funding.js`（顶部滚动条会自动同步，无需重复录入）
   - 替换或更新产业图谱 → 编辑 `maps.js`
   - 更新研讨议题 → 编辑 `topics.js`
3. **切换入口月份**：在 `index.html` 底部将 `<script src="data/2026-11/...">` 批量替换为 `data/2026-12/`（同时可保留上期 `AI产业月度研讨-2026.11.html` 作为历史归档）。
4. **上线前检查清单**：
   - 所有来源（`factSources` / `viewSources` / `sources` / `sourceUrl`）必须为**可点击的一手或主流媒体超链接**；
   - 确认页面无过程文字、无“待补充/预留”占位符、无防御式表述、无“建议邀请”；
   - 确认在 PC 宽屏（1440px / 1280px）和手机竖屏（375px）下侧边隐藏目录、图表、表格均无遮挡和横向溢出。

## 三、内容入选与编辑规则（原附录 E3）

1. **本月重点新闻（Part A）**：
   - 只选真正改变产业格局、商业模式、算力成本结构或技术发展路径的事件；
   - 每页固定结构：**先放背景 → 下方呈现事实与时间线 + 市场看法**；
   - **事实与观点严格分离**：已兑现的结论（如收盘涨跌、合约取消、实体清单）统一归入事实时间线；“市场看法”只保留多空双方的判断逻辑与推演。
2. **机构趋势（Part B）**：
   - 只摘取头部 VC（a16z、红杉等）与前沿调研机构（拾象等）的**商业模式、定价权与趋势判断**，不复述基础技术科普；
   - 采用“顶部横向核心判断 + 中间可视化结构图 + 底部国内对照/佐证”版式，单页不放讨论问题，所有讨论统一收口到 Part E。
3. **研讨议题（Part E）**：
   - 聚焦**商业趋势、产业现状、商业模式更新与未来发展路径**；
   - 避免过于偏二级市场估值博弈、融资结构细节或纯财务指标类的提问（此类信息作为正文背景即可）。

## 四、投融资跟踪与日报系统对接规范（原 C3 内部方案）

### 1. 数据来源与数据库清单
- **内部日报源**：`https://ai-daily.ihainan.me/`（商业投融资每日汇总，作为月度收敛的一手线索池）
  - 检索 Skill 安装命令：`npx skills add annielxy2000-glitch/ai-daily-search-skill`
- **PitchBook**：美国全量一级市场融资核验与分赛道总量统计（可联系静怡协调账号使用）
- **Crunchbase**：月度全球创投总额与 AI 占比基准（月报公开）
- **IT 桔子 / 投资界 / 36氪**：中国月度投融资明细与首发线索
- **企查查**：中国单笔融资工商变更、新增股东核验

### 2. 自动抓取与入表字段标准
建议向日报系统提出如下结构化落库字段，月末 `T-5` 自动去重合并、`T-3` 人工核验、`T-2` 输出月报：

| 字段名 | 说明 | 入表门槛与口径约定 |
| :--- | :--- | :--- |
| `date` | 首次公开披露日期 | 月度截止为当月最后一个自然日；跨月事件记入首次披露月 |
| `company` / `sector` | 公司名与统一赛道分类 | 赛道分类：基座模型 / 算力芯片 / 推理服务 / 应用 / 具身智能 / 前沿计算 |
| `round` / `amount` | 轮次与融资金额 | 保留原币种，注明“公司口径”或“媒体口径” |
| `valuation` / `investors` | 估值与领投/主要投资方 | 估值标注投前或投后，未披露则留空 |
| `sourceUrl` / `tier` | 原文链接与来源等级 | `t1` 公司公告/首发报道，`t2` 主流媒体；聚合站只作线索不进正式表 |
| 入表门槛 | 规模过滤线 | 美国：单轮 ≥ 1 亿美元（新赛道早期 ≥ 2,000 万美元）；中国：单轮 ≥ 1 亿元或头部产业资本领投 |
