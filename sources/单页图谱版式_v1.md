# 算力行业图谱｜单页版式 v1

## 页面标题

**算力产业链：瓶颈从芯片供给逐步转向电力、交付与资金回收**

副标题：截至 2026 年 11 月，训练与推理需求继续扩张，但各环节的约束和利润分配已经分化。

## 页面结构

采用“横向产业链 + 纵向资金流 + 底部近期变化”三层结构，避免把完整台账压缩成一张看不懂的公司名单。

```text
左 → 右：芯片与存储 → 网络与整机柜 → 电力/液冷/数据中心 → 云与 Neocloud → 模型厂商/企业需求
上方：每一层卖什么、代表公司、主要利润池
下方：近 90 天变化，用 3 条带方向的事件串起来
贯穿箭头：设备交付 → 算力可用 → 按小时/按集群收费 → 按 token/应用收入回收
```

## 主图内容

### 1. 芯片与存储

- 卖什么：GPU、定制 ASIC、HBM、先进封装。
- 代表公司：NVIDIA、AMD、Broadcom、TSMC、SK hynix、Samsung。
- 图内标签：**利润最厚；HBM / CoWoS 锁量**。

### 2. 网络与整机柜

- 卖什么：NVLink / InfiniBand / Ethernet、交换机、光模块、服务器和液冷集成。
- 代表公司：NVIDIA Networking、Broadcom、Arista、工业富联、Supermicro。
- 图内标签：**决定集群有效利用率；规模越大，网络占比越高**。

### 3. 电力、液冷与数据中心

- 卖什么：电力容量、机房、配电、液冷和 powered shell / build-to-suit。
- 代表公司：Vertiv、Eaton、Digital Realty、QTS、Vantage、IREN、CoreWeave。
- 图内标签：**新增瓶颈；通电和交付决定芯片何时变成可售算力**。

### 4. 云与 Neocloud

- 卖什么：GPU 小时、集群长约、推理服务。
- 代表公司：AWS、Microsoft、Google、Oracle、CoreWeave、Nebius、Lambda、Nscale。
- 图内标签：**收入按用量，资产和融资按长期承诺；风险集中在中游**。

### 5. 模型厂商与企业需求

- 卖什么：模型 API、订阅、agent 和企业应用。
- 代表公司：OpenAI、Anthropic、Google、Meta、DeepSeek、国内模型厂商。
- 图内标签：**推理需求增长；单位 token 成本、利用率和客户付费决定回收**。

## 资金流和风险流

用两条细箭头贯穿主图：

- **现金流**：模型厂商 / 企业付费 → 云与 Neocloud → 数据中心与硬件供应商。
- **风险流**：芯片长约和设备折旧 → Neocloud 债务 → 模型厂商最低采购义务 → 下游用量波动。

## 底部近期变化栏

只放三条，每条包含“事件 + 影响层 + 方向”：

1. **供给侧**：HBM、CoWoS 和先进封装继续锁量，芯片供给约束向设备和封装延伸。
2. **基础设施侧**：电力、液冷、并网和施工交付成为新增容量的主要限制，芯片到货不等于算力可用。
3. **商业化侧**：Neocloud 扩产依赖客户长约和债务融资，模型厂商收入增长能否覆盖最低采购与研发投入成为回收关键。

## 图表规则

- 每层最多放 4 至 6 个公司名，其他公司收进“代表玩家”小字或另页台账。
- 公司名不按市值排序，按产业链位置和关系放置。
- 颜色只区分四类角色：硬件、基础设施、算力供给、需求方；不要给每家公司使用品牌色。
- 底部变化栏使用上升、迁移、分化三种箭头，不用堆数字。
- 关键数字最多放三组：GPU / HBM 供给、可用容量、Neocloud 利息或利用率。具体数字在后续数据页展开。
